### Reproduction and remaining limits

`pnpm exec tsx --test tests/routing-evidence-replay.test.ts` regenerates the exact
E/F/G blinded rows and mappings, alongside A–D, from a relocated checkout.
The [original join procedure](2026-09-25-development.md#blinded-output-assessment)
applies unchanged: use the corresponding published raw artifact, generate a
fresh local mapping, copy the retained annotation unchanged, and run the
[join script](runs/2026-09-25-jev-join-routing-assessments.py). Source filenames
relocate; hashes, case identities, grades, aggregates and paired usage stay fixed.
Integrity replay does not re-grade or validate the agent judgments.

These are adaptive development results on seven synthetic intents, repeated
across catalog sizes. Neither repeated success on clear tasks nor the separate
[200/200 proposal-review result](../calibration/2026-09-25-question-set-v4.md)
establishes held-out calibration. The remaining measured routing failures are
provider-contract failures; retain the strict unavailable outcome and investigate
the probability-sum discrepancy before claiming full benchmark saturation.
An actual clarifying question from the host also remains a separate delivery
step. No model, policy threshold, fixture label or distribution validator was
changed to improve a score.
