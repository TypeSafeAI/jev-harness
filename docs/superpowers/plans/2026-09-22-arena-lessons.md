# Per-run lessons

Implement local, deterministic analysis of a settled Arena snapshot. Preserve routing policy, host execution boundaries, storage schema and API-key behavior.

- Derive paired input/time comparisons including Jev overhead; distinguish unknown, partial, cancelled and failed evidence.
- Prioritize concrete experiments for routing overhead, tool exposure/activity, rejected calls, cache differences and output differences. Separate observation from hypothesis; do not infer answer quality, causality or monetary savings.
- Show a concise takeaway and an overlay with measured evidence, recommendations and a repeatable evaluation plan. Recompute for reopened history and include versioned analysis in downloads.
- Verify numeric edge cases, outcome gating, deterministic output, inert rendering, history/export lifecycle and mobile/keyboard use. Run typecheck, offline tests, isolated production build and secret checks before signed delivery.
